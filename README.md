# FUSE診断 〜あなただけの特殊能力〜

16の場面（ヒーロー映画のワンシーン）に答えると、あなただけの特殊能力が覚醒する診断サイト。
静的HTML/JSのみ（サーバーなし）。結果は全82,944通り、URLのコードで再現・共有できます。

## 遊び方（開発中の開き方）
`index.html` をブラウザで開くだけで動作します（データは全てローカルJS）。

## 構成
- `index.html` — 画面（トップ＋プロローグ／質問／結果）と判定エンジン
- `data.js` — 質問16問・配点・特性・系統・代償・発動条件・相互作用・プロンプト素材の辞書
- `cores.js` — 96能力コア辞書（`docs/cores.json` v3 から生成）
- `assets.js` — サンプル素材（背景3枚＋ロゴ3枚を data URI 化した暫定版）
- `docs/` — 設計図（DESIGN.md）、辞書の正本JSON、配色マップ

## 実装済み（v0.1）
- プロローグ → 全16問 → 結果カード（横長4:3／縦長9:16の二刀流切替）
- 判定：6パラメータ（主+6／副+3、正規化）→ 18特性・8系統・12形態・代償・発動条件・覚醒タイプ・指向スコアによる陣営（5段階表示）
- 結果カード：SVGフィルターによる覚醒タイプ別縁取り、レーダーチャート、特性チップ、代償タグ
- 共有：結果URL（コード入り）をコピー／Web Share。URLを開くと結果が再現される
- キャラクター生成プロンプト：結果から機械的に英語／日本語プロンプトを合成（画風3種）
